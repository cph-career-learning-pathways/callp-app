# Career & Lifelong Learning Pathway (CaLLP) Application

A web application designed to help Cal Poly Humboldt students and alumni identify career-related skill development needs, discover relevant external learning resources, and plan their learning around personal goals and availability.

## Project Status

This project is currently in initial planning and development.

## Purpose

The application serves as a streamlined intermediary between students/alumni and existing learning resources. It is intended to help users:

- Identify skills they want to develop.
- Discover learning resources relevant to their goals.
- Build skill development plans around their availability and target dates.
- Track progress toward their learning goals.
- Connect with relevant learning and career platforms.

The application does not host its own learning modules or lessons.
